# SustLink · 科大校园社区

当前版本：**v0.2.0**。本次跳蚤市场整合及交互更新详见 [版本更新记录](CHANGELOG.md)。

独立的电脑浏览器论坛原型，包含滚动校园插画入口页和可操作的论坛。主要适配 1440px 与 1024px 桌面宽度，较小屏幕提供基本布局回退。

## 本地启动

需要 Node.js 22.18+（本次使用 24.14）与 npm。在本目录执行：

```powershell
npm install
npm run dev
```

打开 <http://127.0.0.1:5174/>。论坛可直接访问 <http://127.0.0.1:5174/forum>。

如果 Windows 限制了用户目录下的 npm 缓存，可改用项目内缓存：

```powershell
npm install --cache .npm-cache --registry https://registry.npmjs.org
```

## 能体验什么

- 消息中心：上方查看收到的赞／收藏和回复，下方展示商品咨询与同学私聊；支持按昵称发起私聊、草稿、未读标记及全部已读。仍为本地演示，不会向其他用户真实投递消息。
- 开场、科大湖、图书馆、教学楼四个校园场景；正常纵向滚动、章节导航、轻微视差、全程可进入论坛。
- 七个板块：校园资讯、日常生活、学习交流、社团活动、跳蚤市场、失物招领、匿名树洞。置顶、最近回复／最新发布／热门排序，每页 20 条主题。
- 整条帖子可点击进入，板块标签保持独立跳转；连续平面列表取消悬浮效果。首页与板块页只显示标题及必要信息，不显示正文或媒体预览；搜索与个人中心保留摘要、图片缩略图和文件数量辅助查找。回复数和浏览量集中在底部信息栏。
- 演示登录，发帖、正文与文件预览、草稿自动保存、回复、引用楼层、只看楼主、粉色爱心点赞和黄色书签收藏。
- 新主题标题最多 20 个可见字符（中文、英文、表情均按可见字符计数），支持中文输入法；旧帖原样保留，超长旧草稿须缩短后发布。发布页控件使用统一的浅色背景反馈，无粗聚焦框、光晕或悬停抬升。
- 回复支持独立点赞／取消点赞、本地持久化，以及时间正序／时间倒序／点赞最多排序；排序写入 URL，楼层编号与引用保持不变，点赞相同时优先较早的回复。
- 列表的回复／浏览统计采用固定列宽、数字右对齐与等宽数字；1 万起缩写为 `1万`、`1.7万` 等，悬停数字区域可查看完整数量。
- 主题与回复支持图片放大、原生视频播放和附件下载。每条最多 10 个文件；图片 ≤10 MB、视频 ≤100 MB、附件 ≤30 MB。支持 JPG/PNG/WebP/GIF/AVIF、MP4/WebM/OGG/MOV、PDF、Word、Excel、PPT、ZIP/RAR/7Z、TXT/CSV/MD。视频能否在线播放取决于浏览器对文件编码的支持，不支持时可下载。
- 个人主页点击头像上传图片，自动居中裁切为 256px 方形头像；更新普通帖子与顶部头像，匿名主题仍使用匿名标识。
- 发布页顶部返回入口显示来源名称，如「学习交流」「搜索结果」「收藏」或原主题标题；退出恢复来源页面、查询条件、分页与滚动位置。从地址栏直接进入发布页时显示并返回「论坛首页」。
- 有附件的主题在标题末尾显示图片、视频、文件类型图标，每种类型最多一个；悬停可查看各类数量，不增加首页正文或媒体预览。回复／浏览统计列间距为 10px。
- 个人回复记录、引用块、右侧今日话题与公告卡均支持整容器进入；文件附件行支持整行下载。板块标签、公告列表入口和视频播放等独立操作保持各自用途。
- 详情页的回复排序、编辑框和上传按钮取消粗焦点轮廓与光晕，使用柔和背景反馈；键盘聚焦仍有背景提示。发布页标题、正文、板块选择与附件控件也使用同样的背景反馈。
- 标题和正文搜索、板块筛选、示例通知跳转与已读状态、资料编辑、个人主题／回复／收藏。
- 匿名树洞的列表、楼层、引用与通知使用一致的匿名身份。

所有数据均为演示内容，使用固定的「湖边同学」账号。没有真实账号认证、后端、多人同步、私聊、AI、支付或管理后台；没有发布到公网。用户输入按文本渲染，不执行 HTML。匿名是展示逻辑，本地数据中仍有作者 ID，不提供真实身份保密。

文字与文件信息保存在当前网站来源的 localStorage，键为 `sustlink.forum.v1`；文件内容及头像保存在 IndexedDB `sustlink.media.v1`，不会上传服务器。刷新后保留，清除网站数据后删除。`localhost` 和 `127.0.0.1`、不同端口之间不共享数据；更换网络不影响同一浏览器内的本地地址。不会读取或覆盖现有小程序及手机端原型的数据。旧电脑版论坛的「求助问答」主题与草稿自动归入「日常生活」，原帖子、回复和收藏保留。

存储失败时会明确提示。文字更改保留在当前页面内存中，刷新可能丢失；文件保存失败不会添加到内容。移除文件会取消本条内容中的关联，清除网站数据可彻底释放本地文件空间。

## 代码与接口

新增入口文案为「发布新笔记」，个人中心标签为「笔记／回复／收藏」。自己发布的笔记在详情页主帖操作栏右侧提供「删除」：确认后连同全部回复、点赞、收藏、回复点赞和关联通知一并移除，按来源返回个人主页或所属板块。刷新后保持删除结果，旧链接显示内容不可用；本地写入失败时保留原内容。未被其他内容、草稿或头像引用的附件文件会清理。

回复排序采用自适应菜单：下方空间不足时向上展开，箭头同步朝上；支持鼠标、方向键、Home／End、Enter／空格、Escape 和 Tab。排序继续保留在 URL 中。

侧栏「个人主页」进入 `/profile`，默认展示「笔记」；「回复／收藏」仍是主页内的标签。从个人主页各标签打开笔记后，详情返回入口显示「个人主页」，保留原标签、页码与滚动位置，刷新或切换回复排序后仍可返回。从板块进入或直接访问详情时保持原板块返回逻辑。

主帖与自己的回复均在操作栏右下角显示垃圾桶图标＋「删除」，与该行点赞按钮对齐。回复删除会清理对应点赞、通知和不再使用的附件，其他回复及楼层号保持不变；引用处显示「引用的内容已删除」，新回复不复用已删除楼层号。仅含附件的引用提示为「点击查看」。

回复删除权限：回复作者可删除自己的回复；笔记楼主可删除自己笔记下的任意回复，但不能删除他人笔记下其他人的回复。笔记和回复删除成功后不显示浮动成功提示，删除确认与失败提示保留。

- `src/Landing.tsx`：校园章节、静态 SVG 内嵌、视差与离屏清理；减少动态效果时使用静态插画。
- `src/illustrations/`：四幅原创可编辑 SVG，保留命名图层；详情见 [插画参考记录](./ART_REFERENCES.md)。
- `src/Shell.tsx`、`src/pages.tsx`：论坛布局与各业务页面。
- `src/types.ts`：`User`、`Board`、`Topic`、`Reply`、`Notice`、`Draft`、`ForumState`。
- `src/store.ts`：加载／校验／保存、搜索排序、匿名身份、发布与回复操作；后续服务端接入从此层替换。
- `src/context.tsx`：共享状态、演示会话、存储反馈与登录弹窗。
- `src/Media.tsx`、`src/media-store.ts`：上传、预览、下载、头像裁切与本地文件读写。
- `src/navigation.ts`：发布页来源与浏览器历史滚动恢复；`src/refinements.css`：卡片留白、上传布局、搜索焦点与互动反馈。

路由：`/`、`/forum`、`/board/:boardId`、`/topic/:id`、`/new`、`/search`、`/messages`、`/profile`。主题楼层支持片段链接，列表筛选与分页写入 URL。后续静态托管时需将未知文件路径回退到 `index.html`，以支持深链接刷新。当前 Vite 开发／预览服务已支持。

## 验证

```powershell
npm test
npm run build
# 保持 npm run dev 在另一个终端运行，然后执行：
npm run test:e2e
```

浏览器测试默认使用本机 Chrome 的无头模式；若没有 Chrome，可调整 `playwright.config.ts` 的 channel 或安装 Playwright Chromium。先启动开发服务可避免 Windows 环境下自动服务回收等待。测试截图输出到 `test-results/`，该目录不纳入 Git。

`npm run preview` 可预览生产构建。构建后的字体、图标、SVG 和脚本均在本地，不依赖运行时外部图片或字体服务。

视觉与验收记录见 [DESIGN.md](./DESIGN.md) 和 [VERIFICATION.md](./VERIFICATION.md)。

二级分类已接入：点击排序栏右侧分类图标展开筛选，支持发布前选择分类、搜索联动及返回恢复；已发布笔记的分类只读。结构与完整交互见 [SUBCATEGORY_PROPOSAL.md](./SUBCATEGORY_PROPOSAL.md)。界面名称与动效术语见 [UI_GLOSSARY.md](./UI_GLOSSARY.md)。

## 手机版原型

[sustlink-ui-preview/](./sustlink-ui-preview/) 是 SustLink 社区面向手机的 HTML 原型，准备迁入 Kotlin/Compose Android App。它与本目录的桌面论坛**共享品牌与视觉方向，但不是同一套代码**，没有可复用的构建设施，直接双击其中的 `SustLink_整合预览.html` 打开即可。
