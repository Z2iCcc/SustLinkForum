# 分类发布集成

入口 `/new?board=market`、`/new?board=clubs`、`/new?board=lost`。论坛板块页原发布按钮也进入相应表单。其他板块沿用通用笔记编辑器。

- 跳蚤市场：闲置／求购、物品类型、价格／预算、免费赠送、图片、交接区域、交接方式、议价。闲置至少一张实物图片。
- 社团活动：活动／招新／回顾；按类型提供组织、时间、地点、报名、人数及介绍字段。结束严格晚于开始，报名截止不晚于开始，回顾日期不能在未来。
- 失物招领：丢失／拾到、类型、日期、时段、地点线索、照片、描述及拾到物品暂存位置。日期不能晚于今天。

`model.ts` 管理数据结构、验证、旧分类映射、草稿切换及时间边界；`BoardPublisher.tsx` 接入论坛状态和 IndexedDB 附件；`controls.js` 管理已确认的共享日历、年份、滚动／拖拽时间、下拉选择和提示，组件卸载时清理事件与浮层。两份 CSS 均限定发布页范围。

新增字段保存在 `Topic.publishing`，正文只保留用户填写的文本，未加入新详情模板或列表预览卡片。旧主题没有该字段仍可读取。为保持现有筛选展示，物品细分类型映射到原有市场分类，社团与失物类型映射到原分类；完整细分值仍保存在发布数据中。

草稿持续使用 `sustlink.forum.v1`，按板块与发布类型缓存在 `publishDrafts`。切换后可恢复，发布只移除已发布类型的缓存。后台上传完成时归入源草稿；附件引用检查包含缓存草稿，避免删除仍被其他草稿使用的文件。新增表单初始为空，不携带预览中的样例资料。当前论坛仍为单浏览器本地交互原型。

验证：

- `npm run build`：TypeScript 与生产构建。
- `npm test`：16 项数据与规则检查。
- `npx playwright test tests/browser/publishing.spec.ts`：发布持久化、图片恢复、类型／板块草稿、日历与年份、时间拖拽及顺序、下拉选择、隐私提示、1440 / 1024 / 655 / 390px 对齐与浮层边界。
- 已回归 `categories`、`content-entry`、`quiet-content`、`refinements`、`note-management` 浏览器用例，覆盖旧列表、详情、通用编辑器、附件、删除和来源返回。
