# SustLink UI 整合预览

双击 **SustLink_整合预览.html** 即可打开全部页面。

首页左上角进入校园 AI，右上角进入搜索；底部可切换首页、集市、发布、消息、我的。点击帖子打开详情，点赞、收藏、评论和发布都可本地操作。

浏览器中的照片需要联网；文字海报、图标和页面交互无外部依赖。图片都是示意配图，并非真实校园照片。

AI 和聊天为本地演示，不会请求 AI 服务或发送消息。发布、资料等仅保存在当前浏览器，不会改动原生 Android App。

查看「设计规范与交互说明.md」了解尺寸、颜色、页面职责、验证情况和迁移方式。

可维护源码：index.html、styles.css、app.js。修改源码后需要重新内嵌 CSS/JS 才会更新单文件版本。
