# SustLink · 原稿保真修订

## Direction

学生在教室、食堂和宿舍用手机浏览校园内容，浅色页面适合日常阅读。基于用户原始 HTML，保留白色页面、浅蓝图片底、灰色文字区、蓝色选中和个人简介块。

## Typography

统一系统无衬线字体；字号使用 CSS rem 令牌。昵称 24px，页面标题20px，顶部/分类16px，正文和卡片标题14px，辅助信息12px，非核心角标11px。字重仅400/500/600/700，卡片标题600；固定两行空间，超出省略，详情显示全文。

没有查到小红书官方公开且可验证的完整 App 字号表，不把第三方猜测作为官方值。参考 Apple 官方 Typography 的语义分层与动态字体原则，结合用户截图制定本项目字阶：https://developer.apple.com/design/human-interface-guidelines/typography

## Layout

顶部：48px AI 入口 / 44px 搜索框 / 48px 搜索入口。分类：纯文字，选中蓝字与独立移动横杠，不使用胶囊底。

两列网格，外边距12px，间距12px；同一视口卡片封面比例7:6、标题空间与底部元信息高度一致。圆角16px；支持时增强为 superellipse 连续曲率圆角，其他浏览器退回标准圆角。

个人页回归白底、头像、昵称信息、编辑操作、灰色个人简介块、内容分类，新增统计与快捷入口不占据原稿主布局，功能可从个人菜单进入。

## Elevation

卡片：低层柔影。编辑按钮与头像：中层柔影。输入浮层/弹窗：更宽更轻的高层阴影。只在需要表达层级的位置使用，不给每个元素加阴影。

## Motion

按下160ms，内容切换200ms，移动下划线260ms；缓动 cubic-bezier(.22,1,.36,1)，无弹跳。横杠使用 transform 平移，字体颜色渐变，布局尺寸不作动画。底部文字只有选中时可见，预留文本位置，避免底栏高度跳动。发布永远只显示图标。

## Persistence

保留上一版所有本地数据逻辑；本次为 UI 修订，不更换存储键，不清空用户数据。
