# SustLink · HTML 界面整合原型

更新时间：2026-09-06。基于用户提供的「首页1.1.html」「用户.html」和四张参考截图制作。

## 这次的范围

先确认 HTML 的视觉与交互，再迁移到原生 Android Compose。本次没有修改 Android 工程，也没有接入账号、支付、真实聊天或大模型服务。

保留原稿蓝灰白方向、双列内容、个人简介及内容分类。参考截图的信息组织：左上 AI、右上搜索、独立搜索页、个人资料页和统一五项底部导航。移除固定 375×812 手机壳、伪状态栏、灰色占位卡片及发光下划线。

## 打开方式

- 推荐：直接双击 `SustLink_整合预览.html`，CSS、JS 和 SVG 图标已内嵌，无需安装依赖。
- 源码入口：`index.html`，搭配同目录 `styles.css` 和 `app.js`。
- `#home`、`#profile`、`#search`、`#ai`、`#market`、`#messages` 可作为初始预览页。例如在地址末尾加 `#profile`。
- 电脑顶部有 360 / 390 / 430px 宽度选择。手机上隐藏预览工具并占满可见视口。
- 照片来自 Unsplash 外链，为示意素材，不是陕科大实拍。联网时加载照片，失败时保留占位封面；图标及文字海报不依赖网络。
- 浏览器对 file:// 本地存储的支持可能不同。需要稳定测试跨次保留时，使用同一个本地 HTTP 地址访问。不同文件、浏览器和地址的数据不会自动互通。

## 页面与路径

| 页面 | 可以操作的内容 |
|---|---|
| 首页 | 关注/发现/校园频道，分类过滤，双列瀑布流，点赞，进入详情 |
| 搜索 | 输入并提交，最近搜索，热门词，清空记录确认，匹配结果/空状态，搜索我的内容/闲置 |
| 校园 AI | 推荐问题，文字输入，多轮消息展示，新建对话；答案为本地预设 |
| 我的 | 简介、统计说明、笔记/收藏/赞过/闲置/搭子切换，编辑资料，浏览历史，菜单 |
| 集市 | 闲置列表、分类、搜索、商品详情；无真实支付 |
| 消息 | 示例会话和本地发送，AI 入口，通知说明；不会向他人发送 |
| 发布 | 标题、正文、分类、闲置价格、可选本地图片、校验、发布到我的页面 |
| 详情 | 正文、点赞、收藏、添加本地评论、分享文案、返回来源页 |

底部导航固定为：首页 / 集市 / 发布 / 消息 / 我的。所有标签保持显示，避免选中时导航跳动。搜索、AI、详情、编辑、发布属于子页，不展示底部主导航。

自己的头像入口进入我的页面；其他示例作者暂显示资料介绍弹窗。通知、统计显示说明状态，未构建真实关注关系。分享复制文案，不生成可公开访问的内容链接。

### 字体与密度

- 中文系统字体回退：PingFang SC / Microsoft YaHei / Noto Sans CJK SC / sans-serif。
- 常规页面标题 20px，AI 问候 26px，个人昵称 23px。
- 卡片标题 14px，约 1.55 行高，最多两行，超出省略。
- 正文 14px，较长详情约 1.9 行高；输入文字 16px。
- 辅助信息 11–13px；10px 只用于非核心标签、演示提示等。
- 正文常规字重，标题 600–650。不以发光、重阴影制造选中态。

### 间距与尺寸

- 4px 基础间距步长：4 / 8 / 12 / 16 / 20 / 24 / 32。
- 常规页面左右留白 16–20px。
- 信息流单独采用 8px 外边距和 8px 列间距，保留照片优先的高内容密度。
- 列表卡片圆角 10px，通用组件圆角 12–16px，胶囊输入框 24px。
- 图标常用 24px，普通图标按钮点击容器 48×48px，卡片小操作与分类大多 44px 高。
- 主按钮至少 48px；导航可点区域至少 54px 高。
- 不把所有照片裁成同一高度。两列独立排列，按预估卡片高度分配，减少规则网格的大块留白。
- 个人页顶部使用轻浅蓝背景；保持头像、昵称、统计、简介、快捷入口、内容 Tab 的顺序。

### 适配与可访问性

- viewport 使用 width=device-width、viewport-fit=cover，不禁止缩放。
- 手机断点 ≤600px：无模拟手机边框，宽度随设备，高度跟随动态视口。
- 桌面预览：可切换 360/390/430px，最大高度 860px。
- 顶部/底部使用 env(safe-area-inset-*)，不绘制假的系统时间或 Home Indicator。
- 输入区和列表使用 flex 分配空间；VisualViewport 改变时跟随高度，避免键盘覆盖输入。
- 列表可以滚动，分类横向滚动。没有全页横向滚动。
- 按钮提供可访问名称，选中态用 aria-pressed / aria-selected / aria-current，表单有 label。
- 弹窗使用原生 dialog，支持 Escape；焦点关闭后尽可能归还触发按钮。
- 尊重 prefers-reduced-motion。

CSS px 是网页逻辑像素。迁移 Compose 时，间距/尺寸以 dp、字体以 sp 表达，不能将整页截图的物理像素机械照搬。

## 数据与源码

- `styles.css`：集中配色、尺寸、布局与响应式规则。
- `app.js`：图标、示例数据、页面渲染、导航、本地状态。
- localStorage 的键：`sustlink-prototype-v1`。
- 保留：点赞、收藏、资料、搜索历史、浏览历史、本地发布内容、评论。
- 不持久化：AI 会话、消息演示、未发布草稿（本次页面会话内保留）。
- 图片仅支持 JPG/PNG/WebP，单张 2 MB 内；以 data URL 保存到本地浏览器，存储空间受浏览器限制。
- 持久化写入失败时有提示，当前会话仍保留内存数据。
- 所有输入内容按文本转义，不作为用户 HTML 执行。
- 集市分类、AI 回答、粉丝统计和通知均是原型数据，不能用于验证真实业务。

## 迁移原生 App 的建议顺序

1. 先确认首页、搜索、AI、个人页的视觉与导航。
2. 将色彩和文字样式写入 Color.kt / Type.kt / Theme.kt。
3. 提取统一的顶部栏、底部导航、帖子卡片、标签、输入框与空状态。
4. 分页面实现 Compose UI，保留现有 Repository / Room 的业务数据入口。
5. 对接真实登录、图片、搜索与聊天时，再逐项替换演示数据，并补齐加载/失败/权限状态。
